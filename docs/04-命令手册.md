## 0. 怎么发命令

- **私聊直接发**，不用前缀：`统计`、`/统计`、`@梦屿 统计` 三种都行（`friend_message_needs_wake_prefix = false`，`wake_prefix = ["/", "@梦屿", "@大肥鱼梦屿"]` 只是可选的唤醒方式）。
- 命令要**单独一条**发，别夹在句子里（夹在句子里会被当成聊天，不会命中命令）；参数用空格分隔。
- 权限三档：
  - `everyone` — 任何人可用（你的私聊里就是你能用）
  - `admin` — 仅管理员，即 `admins_id = ["OWNER_QQ"]`（你自己）
  - `shared_group_admin` — 群共享管理（**当前群聊不可用，等同失效**）
- 群聊整体被白名单拦在第 2 阶段，下面所有命令**只在私聊有效**。
- 25 条的构成：内置 11 + 自我学习 8 + 联网搜索 1 + 长期记忆 1（组）+ 表情包 1（组）+ 额度 1 + 延迟测试 1 + 生活状态 1。
- **`/急事` 不算注册命令**（不占这 25 条）：它是 `astrbot_plugin_life` 睡眠闸门里识别的文本，仅所有者可用，睡着时每日 3 次叫醒；用法 `/急事 一句话`。

## 二、联网搜索（`astrbot_plugin_anysearch`）

**API 里只注册了一条 `anysearch`**，`extract` / `batch` / `help` 是它内部解析的单词，不是独立注册的子命令（所以 `anysearch help` 不会出现在命令列表里，但确实能用）。

| 命令 | 别名 | 说明 | 权限 |
| --- | --- | --- | --- |
| `anysearch <关键词>` | `websearch`、`搜索` | 实时搜索，固定返回 5 条结果 | everyone |
| `anysearch extract <url>` | — | 提取网页正文 | everyone |
| `anysearch batch <词1,词2,词3>` | — | 批量搜索（最多 5 个词，每个 3 条） | everyone |
| `anysearch help` | — | 插件自带帮助 | everyone |

补充：
- 直接发一个 http(s) 链接，也会自动走正文提取。
- `api_key` 为空时走匿名额度，**实测可用**（`client.py:22` 只在 key 非空时才加 `Authorization` 头）；要更稳的额度去 https://anysearch.com/console/api-keys 免费申请后填进插件配置。
- 她也可以不靠命令自己搜（见第九节工具表）。

## 三、长期记忆（`astrbot_plugin_livingmemory`）

命令组：`lmem <子命令>`。注意 **组本身是 `everyone`，但 11 个子命令全是 `admin`**。

| 子命令 | 说明 |
| --- | --- |
| `lmem status` | 查看记忆系统状态（条数、作用域、索引情况） |
| `lmem search <关键词>` | 搜索记忆 |
| `lmem forget <ID>` | 删除指定记忆（说错话记错了用这个） |
| `lmem summarize` | 立刻为当前会话触发一次总结（把最近对话压成记忆） |
| `lmem reset` | 重置当前会话的长期记忆上下文（不动数据库） |
| `lmem rebuild-index` | 手动重建向量索引（换 embedding 模型后要跑） |
| `lmem rebuild-graph` | 手动重建记忆图谱索引 |
| `lmem migrate-scope <scope>` | 把已有记忆迁移到指定作用域（user / session / global） |
| `lmem cleanup [preview\|exec]` | 清理历史消息里注入的记忆片段，默认 preview 预览 |
| `lmem webui` | 查看记忆 WebUI 的访问地址 |
| `lmem help` | 帮助 |

> 这 11 条是从 API 逐条对出来的，顺序和面板「插件管理 → 命令」里一致。

## 九、生活状态（`astrbot_plugin_life`，自建）

全部 `admin` 权限，共 1 条命令（带 9 个子用法）：

| 命令 | 说明 |
| --- | --- |
| `/life` | 打印当前状态渲染：此刻在哪/在做什么/什么感觉、`self` 四字段（未设置就写「未设置」）、四项驱力、当前判断 |
| `/life why` | 查判断理由：此刻与闲置分钟、四项「当前 / 目标」驱力、上课/睡觉/静默输入、`decision`（action/reason/value/at）、阈值、安静窗口 |
| `/life files` | 数据目录、`state.json` / `heartbeat.json` / `proactive_stats.json` 是否存在、journal 路径、`boot_id`、推进次数、作息模块是否加载 |
| `/life today` | 今天的作息时间线（journal `fact` 按 `slot_key` 去重）+ 下一次状态变化；没记录就明说没有 |
| `/life diary [YYYY-MM-DD]` | 按天读 journal，汇总 fact 与 self 成日记；不写聊天摘要，空日直说没有，缺日不建文件；21 点后自动落盘当天、补昨天 |
| `/life stats` | 最近 7 天主动消息触发来源：`state`（状态提前）/`timer`（定时器）/`manual`（WebUI 手动，不进分母），以及状态触发占比（目标 ≥33.3%） |
| `/life params` | 看 `params.json` 的 version 与四组参数（structure/tuned/drift/behavior）；`/life params set behavior.urgent_daily_limit 3` 改值，`/life params rollback 2` 回滚 |
| `/life handover` | 看所有会话的三句交接与补漏；`/life handover clear` 清空 |
| `/life decline` | 手动进入安静窗口（2 小时）：`decision` 立刻转 `decline`，主动消息不发也不提前；到期自动失效 |
| `/life clear` | 提前结束安静窗口 |

> 这些只是「看」与「临时开关」，不改状态。她的状态由插件按作息与驱力推进，她自己能通过 `life_update` 工具改 `self` 四栏（活动/地点/心情/备注），也能通过 `life_decline` 说「到几点之前先别找我」。要改作息表就改 `qqbot\data\life\life_state.py`。
>
> **`/急事 一句话`**（仅所有者，睡着时每日 3 次）：深睡时叫醒她并进入下一档浅睡；浅睡时白名单私聊可以直接叫醒，不必用急事。`/life files` 看今日已用次数。`/急事` 空参数只回用法，不计数。
