# 梦屿 · 一只住在 QQ 里的数字生命

> 她不是客服。她有自己的作息表、一个每小时往前走一步的状态文件、一段记不住全部但会衰减的记忆，和一条只对两个人开放的私聊通道。

**状态**：2026-10-27 · 自用项目，能跑，很多设计还没实现（本文末尾有清单）
**她跑在**：Windows 本地 → QQ NT ←Hook← SnowLuma ←OneBot v11→ AstrBot → DeepSeek

---

## 她是什么

- 一个 QQ 私聊机器人，人格叫「梦屿」：18 岁、蓝发、鲸鱼娘、说话短、不说「首先其次」、被问是不是 AI 会回「? 你才是AI」。
- 只服务**两个**白名单 QQ，群聊一律拦掉——不是能力问题，是不想让她在群里变成贴图机。
- 目标不是「更聪明的助手」，而是**一个状态先于对话存在的角色**：没人说话的那几个小时，她也在过日子。

## 现在能做什么（诚实版）

| 能力 | 怎么实现 | 状态 |
| --- | --- | --- |
| 回复像打字：延迟跟字数走、连发合并、撤回感知 | 本地补丁 `ai_delay` | ✅ 已上线 |
| 「正在输入」+ 长回复先发「我看看。」 | 同上（SnowLuma `set_input_status`） | ✅ 已上线 |
| 允许不完美：错字后补一句更正 | 同上（发完再补、只补短句） | ✅ 已上线 |
| 生活状态一句话注入（「你此刻：周二 09:30，教室，在上课，有点困」） | 纯函数作息表 + 注入补丁 | ✅ 已上线 |
| 生活状态**持久层**：`state.json` + 每小时幂等推进 + 60 秒心跳 | 本仓库 `plugins/astrbot_plugin_life` | ✅ 已上线（新） |
| 长期记忆：向量 + 共现图 + 反思摘要，每轮取 8 条 | `livingmemory` 插件 | ✅ 已上线 |

| 好感度 / 每日心情 / 表达风格 | `self_learning` 插件 | ⚠️ 只采集，没接进对话 |
| 驱力、意愿抽样、世界与具身、恢复 | 见路线图 | ❌ 未实现 |

## 架构

```
        ┌──────────────── 她的一天 ────────────────┐
        │ life/state.json  ← 每小时幂等推进（插件）  │
        │   facts: 时间/时段/推进次数/心跳（系统写） │
        │   self : 活动/地点/心情（她自己填，null=未设置）│
        │ life/heartbeat.json  ← 60 秒一次           │
        └───────────────────┬─────────────────────┘
                            │ 只读注入（一行）
QQ 用户 ──> QQ NT ──Hook──> SnowLuma ──OneBot v11──> AstrBot ──> DeepSeek
                                                        │
                          人格「梦屿」+ 记忆 8 条 + 生活状态 + 6 个工具
```

关键取舍：**状态只有一个写入者**（插件独占），注入只有一个执行点（`ai_delay`），两者不互相抢。

## 快速开始

前提：Windows + AstrBot 4.x + SnowLuma + 一个 DeepSeek key。

1. **装生活状态插件**：把 `plugins/astrbot_plugin_life/` 整个复制到 `qqbot/data/plugins/`，面板里启用，重载。
2. **打补丁**：按 `patches/*.md` 改四个第三方插件（升级插件会覆盖，需重打）。
3. **跑脚本**：先设密码，再执行——
   ```powershell
   $env:ASTRBOT_PASSWORD = "你的面板密码"
   python scripts/list_commands.py --json commands_snapshot.json
   ```
4. **只读工具**：装好后她会多一个 `life_state` 工具；管理员命令 `/life`（`/life files` 看文件位置）。

## 三条设计判据

1. **状态优先**：能被她「陈述」的当下，比多一句人设有效。
2. **未设置就是未设置**：系统不给的字段不许编（`self.* = null`），也不许替他宣称。
3. **允许什么都不发生**：没有意愿时她可以不说话——代码里要有「什么都不做」这个合法分支。

## 路线图（详细版在 `docs/03-运行手册.md` §16）

| 分支 | 一句话 | 状态 |
| --- | --- | --- |
| S1 状态内核 | 生活状态 → 驱力 → 阈值触发动作 | 进行中（状态文件已上线，缺驱力） |
| S2 调度地基 | 单 scheduler + 持久化 jobstore + 恢复自检 | 未开始 |
| S3 记忆取舍 | 强化累加、注入预算、意向驱动检索 | 未开始 |
| S4 关系可见 | 好感度不再封顶且能被她看见 | 未开始 |
| S5 世界与具身 | `world/` 目录 + 每天三件事 | 未开始 |

验收看三件事：**J1** 断联 3 小时后主动开口且对得上状态；**J2** 次日提起昨天自己做的事；**J3** 重启 2 分钟内任务恢复、心跳在跳。

## 不做什么

- 不宣称她有意识；这是运行时行为，不是证据。
- 不做物理仿真 / 3D / 多生命 / 电子宠物 App。
- 不开群聊，不做多用户并发。
- 不追求「像人」的全能，只追求「这一天是连续的」。
